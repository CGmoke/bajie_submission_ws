### 3.3 四条演进线

**题一 · 底盘与关节驱动。** 资源就位 → `t1_move` 原型 → `q1_drive` 五阶段 + RViz → 包围盒净空预检 → 日志与交付自检接入。这条线的重点始终是"别碰地面、别撞机身"，也是最早引入自动化判据的一题。

**题二 · 正运动学与 TF2 复核。** 先搭提交目录，再写 `fk.py` 关节链正解与 `verify_tf.py` 独立复核，之后只有精度层面的修补。一次成型，最稳的一条。

**题三 · Isaac Sim 触碰。** 首版触碰 → GUI 调试 → 删预览、改逐步下压 → 自适应轻触 → 接触判定与归位 → 可见表面假夹取 → 连续稳定帧 → 链式执行与脱离抬升 → 按玩具形态分垂直下压与夹取。11 次提交围绕同一件事：把玩具位移压到最小，同时确认接触是真的。

**工程与交付。** 容器底座 → docs/scripts 入库 → 资源迁入提交目录 → 三题代码迁入 `bajie-demo/src` 并加 `official.lock` → 题三双入口与镜像 → 结构化日志与交付自检 → 修 gitignore 与退出码 → README 复刻指南。形态从"能跑的工作区"收敛到"别人拿到就能复现"。
