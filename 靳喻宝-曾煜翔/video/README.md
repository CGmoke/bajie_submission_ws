录制说明（供后续替换时参考）：

- 题一：`bash src/question1_project/run_q1.sh --gui`，需可用图形桌面；无图形栈时默认的无界面模式作答一致，但录不了演示。
- 题三：需可用内存 ≥ 12,800 MiB、空闲显存 ≥ 6,000 MiB，NVIDIA 驱动落在 535~580。容器模式在 8 GiB 显存下可能于渲染首帧前 OOM（`oom=true`，2026-11-20 实测），建议走原生 Isaac Sim 路径录制，先验证单帧再逐例录制并合成。
- 压缩：720p / 25~30 fps 起压，平均码率约 1.8 Mbps，两遍编码，目标大小留到约 27 MB；导出后核对实际字节数。
- 不要用渲染探针、截图或示意动画冒充实录。
